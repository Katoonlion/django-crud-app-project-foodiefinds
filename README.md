## Description 
Foodie Finds is a restaurant tracking app where users can discover restaurants, save places they want to try, and mark restaurants they have visited.

## Background 
I created Foodie Finds because I enjoy discovering new restaurants and keeping track of places I want to visit in the future. I wanted to build an application that allows users to organize restaurant experiences in a simple and visually appealing way.
This project was inspired by restaurant recommendation and food tracking platforms, while also helping me practice full CRUD functionality, authentication, user authorization, and deployment using Django and PostgreSQL.

## User Roles & Features :

### Guest Users
- View restaurant list
- View restaurant details
- Sign up for an account
- Sign in to the application

### Logged-in Users
- Create new restaurants
- Edit restaurants they created
- Delete restaurants they created
- Mark restaurants as:
  - Want to Try
  - Visited
- Add personal ratings and reviews
- View their personalized restaurant list
- Filter restaurants by status
